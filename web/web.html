Basic Html Tags

Comment Tag

Used to write notes inside HTML code. Comments are not displayed on the webpage.

<!-- This is a comment -->

DOCTYPE

Declares the HTML document type and tells the browser to use modern HTML standards.

<!DOCTYPE html>

Anchor Tag

Creates hyperlinks that allow users to navigate to another webpage or location.

<a href="https://example.com">Visit Website</a>

Abbreviation Tag

Defines an abbreviation or shortened form of a word. The title attribute can provide its full meaning.

<abbr title="HyperText Markup Language">HTML</abbr>

Acronym Tag

Previously used to identify acronyms. It is obsolete in HTML5; use the abbr tag instead.

<abbr title="World Health Organization">WHO</abbr>

Address Tag

Defines contact information for the author or owner of a webpage or article.

<address>Contact: example@email.com</address>

Applet Tag

Previously used to embed Java applets in webpages. It is obsolete and unsupported in modern HTML.

<applet>Java applet</applet>

Area Tag

Defines a clickable area inside an image map, allowing different parts of an image to link to different destinations.

<area shape="rect" coords="0,0,100,100" href="page.html" alt="Page">

Article Tag

Defines independent content that can stand alone, such as a blog post, news story or article.

<article>My Blog Post</article>

Aside Tag

Defines additional content related to the main content, such as a sidebar or related information.

<aside>Related Articles</aside>

Audio Tag

Embeds audio content such as music or sound recordings into a webpage.

<audio controls src="music.mp3"></audio>

Bold Tag

Makes text visually bold without adding extra importance or meaning.

<b>Hello World</b>

Base Tag

Specifies the base URL used for relative links throughout an HTML document.

<base href="https://example.com/">

Basefont Tag

Previously used to set the default font, size and color of text. It is obsolete; use CSS instead.

<basefont color="red">

BDO Tag

Overrides the normal text direction and forces text to display in a specified direction.

<bdo dir="rtl">Hello</bdo>

Big Tag

Previously increased the font size of text. It is obsolete; use CSS font-size instead.

<big>Large Text</big>

Blockquote Tag

Defines a long quotation taken from another source. Browsers usually indent it.

<blockquote>Learning is important.</blockquote>

Body Tag

Contains all the visible content of a webpage, including headings, paragraphs, images and links.

<body>Hello World</body>

Break Tag

Creates a line break, moving the following content to a new line.

Hello<br>World

Button Tag

Creates a clickable button that can perform actions such as submitting a form or running JavaScript.

<button>Click Me</button>

Canvas Tag

Creates an area where JavaScript can draw graphics, animations and interactive visual content.

<canvas id="myCanvas" width="300" height="150"></canvas>

Center Tag

Previously used to center text and other content. It is obsolete; use CSS text-align or flexbox instead.

<div style="text-align: center;">Hello</div>

Cite Tag

Identifies the title of a creative work, such as a book, movie or painting. Browsers usually display it in italics.

<cite>The Great Gatsby</cite>

Code Tag

Identifies a piece of computer code within a webpage. It usually displays text in a monospace font.

<code>console.log("Hello");</code>

Col Tag

Specifies properties for one or more columns inside an HTML table.

<col span="2" style="background-color: lightblue;">

Colgroup Tag

Groups columns in a table so that styles can be applied to multiple columns together.

<colgroup><col span="2"></colgroup>

Data Tag

Connects visible content to a machine-readable value, making information easier for computers to process.

<data value="101">Product A</data>

Datalist Tag

Provides a list of suggested options for an input field. Users can select a suggestion or type their own value.

<input list="fruits"><datalist id="fruits"><option value="Apple"></datalist>

DD Tag

Provides a description or definition of a term inside a description list.

<dl><dt>HTML</dt><dd>A markup language</dd></dl>

Del Tag

Identifies text that has been deleted or removed from a document. Browsers usually display a line through it.

<del>Old price</del>

Details Tag

Creates an expandable section that users can open or close to see additional information.

<details><summary>More Info</summary>Hello!</details>

Dfn Tag

Identifies a term that is being defined within a sentence or explanation.

<p><dfn>HTML</dfn> is a markup language.</p>

Dialog Tag

Creates a dialog box or interactive window, commonly used for messages, confirmations and forms.

<dialog open>Welcome!</dialog>

Dir Tag

Previously created directory lists. It is obsolete; use the ul tag for unordered lists.

<ul><li>Documents</li></ul>

Div Tag

Creates a block-level container used to group HTML elements for styling and layout with CSS.

<div class="container">Hello World</div>

DL Tag

Creates a description list containing terms and their corresponding descriptions.

<dl><dt>HTML</dt><dd>Markup language</dd></dl>

DT Tag

Defines a term or name inside a description list.

<dl><dt>CSS</dt><dd>Styles webpages</dd></dl>

Em Tag

Emphasizes text to give it special importance or stress. Browsers usually display it in italics.

<em>Very important!</em>

Embed Tag

Embeds external content, such as a media file or another supported resource, into a webpage.

<embed src="file.pdf" type="application/pdf">

Fieldset Tag

Groups related form controls together, usually displaying a border around them.

<fieldset><legend>Personal Info</legend></fieldset>

Figcaption Tag

Provides a caption or description for content inside a figure element, such as an image or illustration.

<figure><figcaption>Beautiful Landscape</figcaption></figure>

Figure Tag

Groups self-contained content such as images, diagrams, illustrations or code examples, optionally with a caption.

<figure><img src="photo.jpg" alt="Nature"></figure>

Font Tag

Previously changed the font family, size and color of text. It is obsolete; use CSS instead.

<p style="color: red;">Hello</p>

Footer Tag

Defines the footer section of a webpage or section. It commonly contains copyright information and contact details.

<footer>Copyright 2026</footer>

Form Tag

Creates a form used to collect information from users through input fields, buttons and other form controls.

<form><input type="text"><button>Submit</button></form>

Frame Tag

Previously displayed another HTML document inside a section of a frameset. It is obsolete in modern HTML.

<iframe src="page.html"></iframe>

Frameset Tag

Previously divided a browser window into multiple frames, each displaying a separate HTML document. It is obsolete in HTML5.

<iframe src="page.html"></iframe>

Heading Tags

Define six levels of headings, from h1 (most important) to h6 (least important). They organize webpage content into sections.

<h1>Main Heading</h1>

Head Tag

Contains information about the webpage, including its title, metadata, stylesheets and links to external resources.

<head><title>My Website</title></head>

Header Tag

Defines introductory content for a webpage or section, commonly containing a logo, heading or navigation.

<header><h1>My Website</h1></header>

HR Tag

Creates a thematic break between sections of content, usually displayed as a horizontal line.

<hr>

HTML Tag

Defines the root element of an HTML document. All other HTML elements are placed inside it.

<html> ... </html>

Italic Tag

Represents text in an alternative voice or mood, usually displayed in italics.

<i>Scientific Term</i>

Iframe Tag

Embeds another webpage or external document inside the current webpage.

<iframe src="https://example.com"></iframe>

Image Tag

Displays an image on a webpage. The src attribute specifies the image location, while alt provides alternative text.

<img src="photo.jpg" alt="Beautiful landscape">

Input Tag

Creates an interactive field where users can enter information, such as text, passwords, email addresses or numbers.

<input type="text" placeholder="Enter your name">

Insert Tag

Identifies text that has been added to a document. Browsers usually display it with an underline.

<ins>New Information</ins>

Keyboard Input Tag

Represents keyboard input or commands that users should enter.

<kbd>Ctrl + C</kbd>

Label Tag

Provides a descriptive label for a form control, helping users understand what information to enter.

<label for="name">Your Name:</label><input id="name">

Legend Tag

Provides a title or caption for a group of related form controls inside a fieldset.

<fieldset><legend>Personal Information</legend></fieldset>

List Item Tag

Defines an individual item inside an ordered list or unordered list.

<ul><li>Apple</li></ul>

Link Tag

Connects an HTML document to external resources, commonly used to attach CSS stylesheets.

<link rel="stylesheet" href="style.css">

Main Tag

Defines the main content of a webpage. It should contain the central information unique to that page.

<main>Welcome to my website</main>

Map Tag

Defines an image map containing clickable areas that can link to different webpages or destinations.

<map name="world"><area shape="rect" coords="0,0,100,100" href="page.html" alt="Destination"></map>

Mark Tag

Highlights text to show that it is relevant or important in a particular context.

<mark>Important Text</mark>

Meta Tag

Provides information about an HTML document, such as character encoding, page description and mobile display settings.

<meta charset="UTF-8">

Meter Tag

Displays a measurement within a known range, such as a score, rating or storage usage.

<meter value="7" min="0" max="10">7 out of 10</meter>

Navigation Tag

Defines a section containing important navigation links that help users move around a website.

<nav><a href="home.html">Home</a></nav>

Noframes Tag

Previously provided alternative content for browsers that did not support frames. It is obsolete in HTML5.

<p>Alternative content</p>

Noscript Tag

Provides alternative content displayed when JavaScript is disabled or unsupported in the browser.

<noscript>Please enable JavaScript.</noscript>

Style Tag

Defines CSS styles directly inside an HTML document.

<style>p { color: blue; }</style>

Sub Tag

Displays text slightly below the normal text (subscript), commonly used in chemical formulas.

H<sub>2</sub>O

Summary Tag

Defines a visible heading that users can click to show or hide additional information inside a details element.

<details><summary>More Info</summary>Extra text</details>

Sup Tag

Displays text slightly above the normal text (superscript), commonly used for mathematical powers.

x<sup>2</sup>

Svg Tag

Defines a container for creating scalable vector graphics, such as circles, lines, and rectangles.

<svg width="100" height="100"><circle cx="50" cy="50" r="40" fill="blue"/></svg>

Table Tag

Creates a table for organizing information into rows and columns.

<table><tr><td>Name</td></tr></table>

Tbody Tag

Groups the main body rows containing data inside an HTML table.

<tbody><tr><td>Sara</td></tr></tbody>

Td Tag

Defines a regular data cell inside a table row.

<td>Sara</td>

Template Tag

Stores HTML content that is not displayed immediately but can be used later with JavaScript.

<template><p>Hello!</p></template>

Textarea Tag

Creates a form field where users can enter multiple lines of text.

<textarea rows="4" cols="30">Write here</textarea>

Tfoot Tag

Groups the footer rows of a table, usually containing totals or summary information.

<tfoot><tr><td>Total: 500</td></tr></tfoot>

Th Tag

Defines a header cell in a table, describing the information in a row or column.

<th>Name</th>

Thead Tag

Groups the heading rows of a table.

<thead><tr><th>Name</th></tr></thead>

Time Tag

Represents a date or time in a format that browsers and search engines can understand.

<time datetime="2026-11-18">November 18, 2026</time>

Title Tag

Defines the title of an HTML document, which appears in the browser tab.

<title>My Website</title>

Tr Tag

Defines a row inside an HTML table.

<tr><td>Sara</td><td>17</td></tr>

Track Tag

Adds timed text information, such as subtitles or captions, to audio or video.

<track src="subtitles.vtt" kind="subtitles" srclang="en" label="English">

Tt Tag

Previously displayed text in a monospace font. It is obsolete; use CSS or the code tag instead.

<tt>Monospace Text</tt>

U Tag

Marks text with a non-textual annotation, commonly displayed with an underline, such as a spelling mistake.

<u>Mispelled</u>

Ul Tag

Creates an unordered list, usually displayed with bullet points.

<ul><li>HTML</li><li>CSS</li></ul>

Var Tag

Represents a variable in a mathematical expression or computer program.

<var>x</var> + 5 = 10

Video Tag

Embeds a video into a webpage and can provide controls such as play, pause, and volume.

<video src="movie.mp4" controls></video>

Wbr Tag

Suggests a possible line-break location inside a long word or string when there is not enough space.

SuperLongWord<wbr>ContinuesHere
